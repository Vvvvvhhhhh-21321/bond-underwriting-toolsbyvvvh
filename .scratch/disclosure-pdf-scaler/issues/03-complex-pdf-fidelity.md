# 03 — 可靠处理复杂 PDF 页面

**What to build:** 让拼版引擎可靠处理真实披露材料中的横纵混排、旋转页、异常页面边界和轻微页面尺寸差异，并落实最终版面几何与附加内容清理规则，使输出保持正向、清晰、可搜索且没有失效交互对象。

**Blocked by:** 02 — 支持完整页码选择与自适应拼版.

**Status:** completed

- [x] 每页根据有效可见边界和旋转信息确定尺寸与方向，不假定页面框坐标顺序正常。
- [x] 页面尺寸的细微浮点差异不会造成错误分组、错误方向或处理失败。
- [x] 横向和旋转页面保持正向阅读，等比例缩放并在格内居中，不裁切、不拉伸，也不为放大内容而额外旋转。
- [x] A4 纵向拼版页面四周边距为 5 毫米，格间距为 2 毫米；3、5、8 页等未满尾行整体居中。
- [x] 单页分组保持原页视觉、尺寸和方向，同时执行约定的附加内容清理。
- [x] 输出尽可能保留可见文字的搜索和复制能力，不主动降低原图分辨率或以压缩体积为目标。
- [x] 输出移除页面注释和链接，不复制元数据、书签、附件、表单或数字签名。
- [x] 渲染级测试覆盖纵向、横向、旋转、异常页面框和尺寸微差页面，确认无倒置、裁切、拉伸、黑页或越界。
