# 05 — 完成可靠的批量输出流程

**What to build:** 让清单中的所有有效 PDF 能够作为一个批次可靠处理。每份输入独立输出到同一个时间戳文件夹；应用隔离单文件失败、保护源文件和既有结果、清理半成品，并通过进度和完成摘要向用户说明整批结果。

**Blocked by:** 03 — 可靠处理复杂 PDF 页面; 04 — 建立批量文件清单与拖放入口.

**Status:** completed

- [x] 用户每次处理前重新选择输出位置；输出根目录不可写时批次不能启动。
- [x] 开始处理后创建“PDF缩放结果_年月日_时分秒”文件夹，并将每个输入的独立结果平铺写入，不复制父子目录或空目录。
- [x] 输出使用“原文件名_缩放.pdf”；任何冲突通过 `_2`、`_3` 等序号解决，永不覆盖既有文件。
- [x] 写入使用临时文件后提交；单文件写入或处理失败时删除半成品并继续后续文件。
- [x] 无效页码、加密、损坏和无法解析的 PDF 被跳过并记录原因；单个跳过或失败不阻断其他有效文件。
- [x] 若没有任何成功结果，批次不保留空结果文件夹；源 PDF 在所有成功和失败路径中均不被修改、移动或覆盖。
- [x] 运行中显示整体进度和当前文件名；运行期间阻止窗口关闭并提示等待完成，不提供取消入口。
- [x] 全部成功时只显示“处理完成”；存在跳过或失败时列出文件名与原因，并允许复制错误信息；输出目录不生成日志文件。
- [x] 完成后保留当前清单、页码设置和去末页开关状态，以便本次会话内再次处理。
- [x] 高层自动测试验证批次结果结构、处理顺序、失败隔离、重名递增、半成品清理、零成功目录清理和源文件完整性。
