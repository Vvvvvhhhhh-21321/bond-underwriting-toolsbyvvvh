# 04 — 建立批量文件清单与拖放入口

**What to build:** 让用户通过添加文件、递归添加文件夹或拖放建立一个极简 PDF 清单。清单按照稳定顺序展示可处理文件，并提供逐文件页码、移除和清空能力，同时明确处理重复输入、同名文件和非 PDF 文件。

**Blocked by:** 02 — 支持完整页码选择与自适应拼版.

**Status:** ready-for-agent

- [ ] 用户可以一次添加一个或多个 PDF，也可以选择文件夹并递归发现所有子文件夹中的 PDF。
- [ ] 用户可以拖入 PDF、文件夹或二者组合，行为与按钮添加一致。
- [ ] 非 PDF 文件被忽略，扩展名比较不区分大小写，并汇总提示忽略数量。
- [ ] 同一路径只加入一次；不同路径但文件名相同的输入按大小写不敏感规则只保留最先加入的一份，并提示被忽略的文件名。
- [ ] 清单按完整路径自然排序，排序决定后续处理顺序，但主清单只显示文件名、页码框和移除按钮。
- [ ] 用户可以逐项移除文件，也可以通过二次确认清空整个列表。
- [ ] 清单中的页码输入沿用已实现的范围校验和默认范围规则；无效项在对应行明确标红并说明原因。
- [ ] 关闭并重新启动应用时清单为空；本次会话内清单变化保持稳定。
- [ ] 自动测试覆盖递归目录、空目录、混合拖放、重复路径、不同目录同名、大小写扩展名、自然排序、移除和清空。
