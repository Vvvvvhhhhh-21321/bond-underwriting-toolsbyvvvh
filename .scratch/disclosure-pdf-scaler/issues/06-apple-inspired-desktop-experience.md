# 06 — 完成 Apple-inspired 桌面体验

**What to build:** 将完整处理能力整理为清爽、克制且易于首次使用的简体中文桌面界面。视觉采用 Apple-inspired 浅色语言，同时保留标准 Windows 窗口行为，并在常见显示缩放比例下保持清晰可用。

**Blocked by:** 05 — 完成可靠的批量输出流程.

**Status:** completed

- [x] 窗口标题为“底稿pdf缩放打印工具”，默认尺寸约 900×650，可调整大小，并设置不会挤坏控件的合理最小尺寸。
- [x] 空清单显示大型圆角拖放区域、“添加文件”和“添加文件夹”入口，无需说明书即可理解。
- [x] 主界面只保留去末页开关、极简文件清单、清空列表、选择输出位置、开始处理、进度和当前文件等已确认功能，不引入预览、设置页或批量范围。
- [x] 界面采用充足留白、圆角卡片、轻微阴影、细分隔线和克制蓝色强调色，同时使用标准 Windows 最小化、最大化和关闭行为。
- [x] 字体优先使用 `Segoe UI Variable`，中文稳定回退到微软雅黑；在 Windows 100%、125% 和 150% 显示缩放下文本与控件清晰且不重叠。
- [x] 清单可滚动，大量文件不会破坏窗口布局；错误标红、按钮禁用、进度和完成提示具备一致而明确的视觉反馈。
- [x] 仅使用短暂的按钮悬停、文件加入和进度过渡，不出现拖慢工作的显著动画。
- [x] 应用采用白色圆角文档、九宫格页面和蓝色渐变的原创图标，不使用 Adobe 商标。
- [x] GUI 冒烟验收覆盖空状态、添加入口、拖放、清单操作、校验错误、输出选择、处理中状态、关闭保护和完成后保留清单。
