# 01 — 打通单文件 PDF 缩放闭环

**What to build:** 建立可运行的 Windows 桌面应用和批量处理接口的首个纵向切片。用户能够加入一份 PDF、选择输出位置并生成一份独立结果；所选的 2 至 9 页通过原生 PDF 页面变换拼排到 A4 纵向页面，源文件保持不变。该切片同时建立后续工单共用的最高层测试接缝，但不提前实现完整页码语法、批量清单或视觉精修。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 应用可以在 Windows 开发环境中启动，并允许用户选择一份可读取的 PDF 和一个输出位置。
- [ ] 用户可以通过一个最小页面范围选择触发处理，并得到一个独立结果 PDF；结果只含本次选择的页面。
- [ ] 2 至 9 个选中页面直接变换为一个 A4 纵向拼版页，不先栅格化，不裁切或拉伸可见内容。
- [ ] 结果使用“原文件名_缩放.pdf”命名，且不会覆盖或修改源 PDF。
- [ ] 批量处理接口接收有序文件请求和输出位置，返回结构化的成功或失败结果；桌面界面通过该接口工作。
- [ ] 自动测试通过批量处理接口检查结果存在、输出页数及尺寸正确、源文件内容未变化，而不依赖内部 PDF 库或界面实现细节。
