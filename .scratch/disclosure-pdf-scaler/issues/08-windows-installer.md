# 08 — 交付 Windows 安装包

**What to build:** 将已通过真实材料验收的桌面应用打包为可交付的 Windows 10/11 x64 安装程序。普通用户无需 Python 或管理员权限即可安装、通过桌面或开始菜单启动、覆盖升级和卸载，并获得版本 1.0.0 的完整离线应用。

**Blocked by:** 06 — 完成 Apple-inspired 桌面体验; 07 — 通过真实披露材料整批验收.

**Status:** ready-for-agent

- [ ] 生成名为“披露PDF缩放工具_安装程序.exe”的 Windows 10/11 x64 安装包，应用版本显示为 1.0.0。
- [ ] 安装按当前用户进行，不要求管理员权限，目标电脑无需预装 Python 或开发依赖。
- [ ] 安装创建名为“披露PDF缩放工具”的桌面快捷方式和开始菜单入口，二者均可正常启动应用。
- [ ] Windows 已安装应用中可找到并正常卸载本程序；卸载移除程序入口且不影响用户源 PDF 和已生成结果。
- [ ] 再次运行较新版本安装包可以覆盖升级旧版本，无需用户先手工卸载。
- [ ] 安装后的程序保持完全离线，不包含自动更新、遥测或网络依赖。
- [ ] 安装包和应用使用约定的原创图标；未签名版本允许出现 Windows 未知发布者或 SmartScreen 提示。
- [ ] 在 Windows 10/11 x64 上完成安装、启动、处理样例 PDF、覆盖升级和卸载的冒烟验收。
