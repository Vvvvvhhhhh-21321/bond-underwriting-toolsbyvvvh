# 工具目录约定

每个小工具使用一个独立目录：

```text
tools/
└─ <工具名称>/
   ├─ README.md
   └─ source/
```

工具目录中的 `README.md` 至少说明：

- 工具解决的问题和适用场景；
- 使用方法、输入和输出；
- Windows 运行要求；
- 当前版本和已知限制；
- 对应的 GitHub Release。

源码放在 `source/` 中。构建产物、测试输入、运行输出和项目底稿不放入仓库；可执行文件通过 GitHub Releases 发布。

## 隔离原则

- 根目录只维护总仓说明、工具目录索引和全仓忽略规则。
- 每个工具的源码、测试、构建脚本、安装脚本和工具专属文档都放在自己的 `tools/<工具名称>/` 目录内。
- 一个工具不得依赖另一个工具目录中的源码或运行时文件；需要复用时，应先提取为明确的共享库并单独维护。
- 新工具只新增自己的目录和根目录索引项，不直接把项目文件放在仓库根目录。
